# API Reference: Overview & Conventions

## Base URL

| Environment | Base URL |
| :--- | :--- |
| **Development** | `http://localhost:8000` |
| **Production** | Configured via reverse proxy / domain |

Interactive API documentation is automatically generated by FastAPI:
- **Swagger UI**: `http://localhost:8000/docs`
- **ReDoc**: `http://localhost:8000/redoc`
- **OpenAPI JSON Spec**: `http://localhost:8000/openapi.json`

---

## Authentication

All protected endpoints require an HTTP `Authorization` header containing a valid JWT Bearer token:

```http
Authorization: Bearer <your_jwt_access_token>
```

Tokens are obtained by submitting credentials to [`POST /api/auth/login`](file:///d:/Projects/CRM/docs/05-api/auth-endpoints.md). The token encodes user ID, company ID, and role, expiring 8 hours after issuance.

## Standard Error Response Format

The API follows standard RFC 7807 problem details and FastAPI conventions:

### 1. Standard Error (`HTTPException`)
```json
{
  "detail": "Resource not found or access denied"
}
```

### 2. Validation Error (Pydantic 422 Unprocessable Entity)
When request payload validation fails, a structured array of field errors is returned:
```json
{
  "detail": [
    {
      "loc": ["body", "contact_email"],
      "msg": "value is not a valid email address",
      "type": "value_error"
    }
  ]
}
```

### Standard HTTP Status Codes:
- `200 OK`: Request succeeded.
- `201 Created`: Resource successfully created.
- `204 No Content`: Resource deleted or state cleared.
- `400 Bad Request`: Business rule violation or malformed input.
- `401 Unauthorized`: Missing or invalid Bearer token.
- `403 Forbidden`: Insufficient role or permission privileges, or inactive subscription.
- `404 Not Found`: Target resource does not exist or belongs to another tenant organization.
- `422 Unprocessable Entity`: Request body failed schema validation.
- `500 Internal Server Error`: Unhandled server exception.

## Pagination Conventions

List endpoints accept standard offset-limit query parameters:
- `skip` *(integer, default: 0)*: Number of records to skip.
- `limit` *(integer, default: 100)*: Maximum number of records to return.

Example:
```http
GET /api/leads/?skip=20&limit=10
```
